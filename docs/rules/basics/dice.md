# Dice

## Category
Basic Rule

## Summary
Explains how dice rolls are described and interpreted in D&D 3.5e.

## Mechanics
Dice rolls are described with expressions such as “3d4+3,” meaning “roll three four-sided dice and add 3.” The first number indicates how many dice to roll, the number after “d” indicates the type of die, and any number after that is added or subtracted.

### d%: Percentile Dice
You generate a number between 1 and 100 by rolling two different ten-sided dice. One (designated before you roll) is the tens digit. The other is the ones digit. Two 0s represent 100.
