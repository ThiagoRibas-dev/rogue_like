# Multiplying

## Category
Basic Rule

## Summary
Explains how multipliers are applied to numbers and die rolls in D&D 3.5e.

## Mechanics
When applying a single multiplier, multiply normally. When two or more multipliers apply to an abstract value (like a modifier or die roll), combine them into a single multiple, with each extra multiple adding 1 less than its value to the first multiple (e.g., ×2 and ×2 results in ×3).

When applying multipliers to real-world values (like weight or distance), normal rules of math apply.
