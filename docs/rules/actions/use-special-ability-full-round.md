# Use Special Ability (Full-Round)

## Category
Full-Round Action

## Summary
Using a special ability is usually a standard action, but some may be full-round actions, as defined by the ability.

## Mechanics
- **Action Type:** Full-Round Action
- **Required Check:** Varies by ability
- **Success Outcome:** Varies by ability
- **Failure Outcome:** Varies by ability
