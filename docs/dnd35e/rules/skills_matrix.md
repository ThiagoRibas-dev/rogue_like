# Skill Check Mechanics & Summary Matrix

## 1. Skill Check Rules
To resolve a skill check, roll a $d20$, add the character's skill ranks, their governing ability modifier, and any miscellaneous bonuses (racial, feats, equipment).
$$\text{Skill Check} = d20 + \text{Skill Ranks} + \text{Ability Modifier} + \text{Misc Modifiers}$$

*   **Class Skills:** Associated with the character's active class. Ranks cost 1 skill point each. The maximum rank limit is:
    $$\text{Max Class Rank} = \text{Character Level} + 3$$
*   **Cross-Class Skills:** Not associated with the active class. Ranks cost 2 skill points each. The maximum rank limit is:
    $$\text{Max Cross-Class Rank} = \frac{\text{Character Level} + 3}{2}$$
*   **Skill Tricks:** Optional maneuvers purchased for 2 skill points (requires specific skill rank thresholds).

### Special Resolutions
*   **Take 10:** When not threatened, distracted, or in immediate danger, you can choose to treat the $d20$ roll as a flat 10.
*   **Take 20:** When attempting a task with no penalty for failure, you can choose to treat the $d20$ roll as a flat 20. This represents trying repeatedly until you get it perfect, consuming 20 times the normal duration of the task.
*   **Aid Another:** You can assist an ally's check by rolling against DC 10. Success grants your ally a +2 circumstance bonus on their check.
