# The Core Mechanic

## Category
Basic Rule

## Summary
The fundamental process for resolving actions with a chance of failure in D&D 3.5e.

## Mechanics
To determine if a character succeeds at a task:
*   Roll a d20.
*   Add any relevant modifiers.
*   Compare the result to a target number.
If the result equals or exceeds the target number, the character succeeds. If the result is lower, they fail.

## Special Notes
This is the core mechanic for most actions in the game.
