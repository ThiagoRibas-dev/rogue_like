# Dexterity (DEX)

## Category
Ability Score

## Summary
Measures hand-eye coordination, agility, reflexes, and balance.

## Mechanics
Apply Dexterity modifier to:
*   Ranged attack rolls.
*   Armor Class (AC), provided the character can react to the attack.
*   Reflex saving throws.
*   Balance, Escape Artist, Hide, Move Silently, Open Lock, Ride, Sleight of Hand, Tumble, and Use Rope checks.

## Special Notes
Most important for rogues, and characters wearing light or medium armor, or no armor.
