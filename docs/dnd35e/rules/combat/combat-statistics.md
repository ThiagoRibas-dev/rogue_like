# Combat Statistics
## Category
Combat Basics
## Summary
This section summarizes the statistics that determine success in combat, and then details how to use them.
## Mechanics
Combat statistics include:
- Attack Roll
- Attack Bonus
- Damage
- Armor Class (AC)
- Hit Points (HP)
- Speed
- Saving Throws
- Initiative
## Special Notes
This rule serves as an overview for the detailed combat statistics that follow.
