# Death Attacks

## Category
Special Ability

## Summary
Describes attacks that can kill a victim instantly.

## Mechanics
- **Saving Throw:** In most cases, a death attack allows the victim a Fortitude save to avoid the effect.
- **Instant Death:** If the save fails, the character dies instantly. A victim cannot be made stable and thereby kept alive.
- **Hit Points:** A dead character has -10 hit points.
- **Resurrection:** `Raise dead` doesn't work on someone killed by a death attack.
- **Protection:** The spell `death ward` protects a character against these attacks.
