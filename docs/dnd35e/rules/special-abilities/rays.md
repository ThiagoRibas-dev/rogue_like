# Rays

## Category
Special Ability

## Summary
Describes ray attacks, which require a ranged touch attack.

## Mechanics
- **Attack Roll:** All ray attacks require the attacker to make a successful ranged touch attack against the target.
- **Range:** Rays have varying ranges, which are simple maximums. A ray’s attack roll never takes a range penalty.
- **Saving Throw:** Even if a ray hits, it usually allows the target to make a saving throw (Fortitude or Will). Rays never allow a Reflex saving throw.
