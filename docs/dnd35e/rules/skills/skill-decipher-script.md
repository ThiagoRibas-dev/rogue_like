# Skill: Decipher Script
## Category
Skill Rules (A-D)

## Overview
The Decipher Script skill is used to decode ciphers, read unfamiliar languages, or interpret archaic, damaged, or incomplete writings.

*   **Key Ability:** Intelligence (Int)
*   **Trained Only:** Yes
*   **Armor Check Penalty:** No

---

## Mechanics

### Deciphering Texts
*   **Action:** Deciphering a page of text takes **1 minute**.
*   **Resolution:** The DM makes the Decipher Script check for you secretly.
*   **DCs:**
    *   *Standard Text:* **DC 25** (simple messages, journals, basic code).
    *   *Exotic/Obscure Text:* **DC 30** (ancient dead languages, highly specialized magical runes, advanced ciphers).
*   **Success:** You understand the general content of a piece of writing about one page long (or equivalent).
*   **Failure:** You fail to understand the text.
    *   *Wisdom Check:* You must immediately succeed on a secret **DC 5 Wisdom check** (made by the DM). If you fail, you draw a **false conclusion** about the text, believing you translated it correctly.
*   **Retry:** You cannot attempt to decipher the same text again.

---

## Creating and Decoding Ciphers

### Creating a Private Cipher
*   **Action:** Takes **1 week** of uninterrupted work.
*   **Effect:** Creates a private code system that allows you (or anyone with the key) to record information without risk of others reading it.

### Decoding Another's Cipher
*   **Check DC:** **10 + creator's total skill modifier** at the time the cipher was created.
*   **Time Required:**
    *   *First Attempt:* Requires **1 day** of uninterrupted study.
    *   *Subsequent Retries:* Each retry requires **1 week** of uninterrupted study.
