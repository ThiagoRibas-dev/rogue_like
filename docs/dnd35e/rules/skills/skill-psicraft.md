# Skill: Psicraft
## Category
Psionic Skills

## Overview
Use this skill to identify powers as they are manifest, powers already in place, or other psionic effects.

*   **Key Ability:** Intelligence (Int)
*   **Trained Only:** Yes
*   **Armor Check Penalty:** No

---

## Mechanics

### Task DCs and Actions

| Task | DC | Action Required | Try Again? |
| :--- | :---: | :--- | :---: |
| **Identify a power being manifested**¹ | 15 + power level | None | No |
| **Determine discipline via *detect psionics*** | 15 + power level² | None | No |
| **Address a power stone** | 15 + power level | 1 minute | Yes |
| **Identify an active power**³ | 20 + power level | None | No |
| **Identify shaped/created psionic materials** | 20 + power level | None | No |
| **Identify a targeted power after saving against it** | 25 + power level | None | No |
| **Identify a psionic tattoo** | 25 | 1 minute | No |
| **Draw diagram for *dimensional anchor*** | 20 | 10 minutes | No⁴ |
| **Understand a unique psionic effect** | 30 or higher | Varies | No |

¹ *You must sense the power's display or see some visible effect.*
² *If the aura is not a power effect, the DC is 15 + ½ manifester level.*
³ *You must be able to see or detect the effects of the power.*
⁴ *The player does not see the result of this check.*

---

## Synergy and Feats

*   **Class Bonus:** A psion gains a **+2 bonus** on Psicraft checks when dealing with a power or effect from his chosen discipline.
*   **Psionic Affinity Feat:** Grants a **+2 bonus** on Psicraft checks.
*   **5+ ranks in Knowledge (psionics):** Grants a **+2 synergy bonus** on Psicraft checks.
*   **5+ ranks in Psicraft:** Grants a **+2 synergy bonus** on Use Psionic Device checks related to power stones.
*   **5+ ranks in Use Psionic Device:** Grants a **+2 synergy bonus** on Psicraft checks to address power stones.
